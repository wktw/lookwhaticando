# Mochi Meadow 🌱🐄🐱

**Take care of your real life. Grow a tiny meadow of friends.**

A cozy habit tracker for iPhone and Mac. Every habit grows a potted plant, and every check-in earns coins
for capsule machines full of cats, cows, bunnies and friends who move into your meadow.

> Full documentation is written at release. See [`docs/DESIGN.md`](docs/DESIGN.md) for the design bible.

## Quick start

```bash
npm install
npm run dev        # open the printed URL on your PC, or on your phone on the same Wi-Fi
```
